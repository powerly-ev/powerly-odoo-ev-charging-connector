Powerly EV Charging Connector

Connect Odoo with Powerly to synchronize EV chargers and selected charging operations data. The connector helps operators and businesses view key Powerly data inside Odoo for operational follow-up and accounting workflows.

Key features

  • Connect Odoo to a Powerly account using an API key
  • View and manage EV chargers linked to your Powerly account
  • View charging orders and related records inside Odoo (based on enabled features)
  • View charging feedback captured from Powerly (if enabled)
  • Scheduled synchronization using cron jobs (if enabled)

Configuration

  1. Install the module.
  2. In Odoo, open Settings and navigate to the Powerly section.
  3. Enter your Powerly API key and any required connection settings, then save.
Note: You can get your Powerly API Key from Powerly Dashboard -> Tools -> API -> Generate New API Key.

How to use

  • Open the Powerly menus from the main Odoo navigation.
  • Review chargers and orders that are available to your Powerly account.
  • If scheduled sync is enabled, data will refresh automatically based on the configured cron jobs.
